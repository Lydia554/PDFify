🛠️ How to Connect Your Shopify Store to PDFify

✅ Step 1: Create a Custom App

  1. Go to your Shopify Admin → Apps
  2. Click App and sales channel settings
  3. Click Develop apps for your store
  4. Click Create an app
  5. Name it PDFify Connector

✅ Step 2: Set Required Permissions

  • Go to the Configuration tab
  • Enable these permissions:
    • read_orders
    • write_orders (optional)
    • read_products
  • Save changes

✅ Step 3: Install the App

  • Return to the Overview tab
  • Click Install app
  • Confirm installation

✅ Step 4: Copy Your Access Token

  • Go to API credentials tab
  • Click Reveal token once
  • Copy token (shpat_...)

✅ Step 5: Paste the Token into PDFify

  • Paste shpat_... into PDFify
  • Enter store domain: your-shop.myshopify.com
