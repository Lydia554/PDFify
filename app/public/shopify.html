🛠️ Connect Your Shopify Store to PDFify

Follow these steps to connect Shopify and start auto-generating beautiful PDF invoices.

Step 1: Create a Custom App

  • Shopify Admin → Apps
  • App and sales channel settings → Develop apps → Create an app
  • Name it PDFify Connector

Step 2: Set Permissions

  • Configuration → Admin API scopes
  • Enable:
    • read_orders
    • write_orders (optional)
    • read_products

Step 3: Install the App

Return to the Overview tab → Install app → Confirm installation

Step 4: Copy Your Access Token

API credentials → Reveal token once → Copy shpat_...

Step 5: Paste Into PDFify

Paste token & store domain into PDFify settings
