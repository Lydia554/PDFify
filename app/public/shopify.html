🛠️ Shopify Setup Steps

Step 1: Create a Custom App

Go to Shopify Admin → Apps → Develop Apps → Create an App

Step 2: Set Permissions

Enable read_orders, write_orders, read_products

Step 3: Install the App

Return to Overview → Install App → Confirm

Step 4: Copy Access Token

Get token from API Credentials → Reveal token once → Copy

Step 5: Paste Token into PDFify

Paste shpat_... & Store Domain → Done!
